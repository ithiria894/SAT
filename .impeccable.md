## Design Context

### Users

Nicole uses this page while solving SAT Math questions, usually on a phone beside a printed paper. The page must work as an instant visual reference: identify the question type, recall the already-agreed mechanical method, and return to the paper without reading a lesson.

### Brand Personality

Direct, confident, and sharp. It should feel like a personal tactical notebook prepared by a very good tutor: no institutional language, no generic study-app cheerfulness, and no decorative clutter.

### Aesthetic Direction

An editorial exam desk: warm paper, dark ink, hard rules, cobalt annotation marks, and vermilion highlights. Formulae should dominate. Diagrams are functional SVG teaching aids, not decoration. The default is a high-contrast light theme because the page is used beside paper. Avoid generic rounded-card dashboards, gradients, glassmorphism, and AI-looking icon grids.

### Design Principles

1. One glance, one action: every section leads with the locked formula or mechanical rule.
2. Show spatial meaning: diagrams must explain signs, sides, vertices, or scale relationships.
3. Reduce mental sign conversion: use the user's `Vx, Vy` vertex coordinates and preserve the exact `x − (Vx)` substitution method. Treat textbook `h, k` only as an input translation.
4. Adapt for the desk: mobile-first, large enough to read at arm's length, with a formula-only mode.
5. Grow only after mastery: unlearned topics are not presented as usable formulae.
