Vertex form

目的：一眼由方程式讀出轉折點，或者由 vertex 寫返條式。核心係原封不動代入，唔喺腦入面玩正負號。

唯一預設寫法
y = a[x − (Vx)]² + Vy
vertex = (Vx, Vy)
  1. 將 Vx 連符號原封不動放入 x − (Vx)。
  2. 將 Vy 連符號原封不動放喺括號外。
  3. 寫完先處理雙負號；唔好提前心算。
試題寫 h, k，就翻譯成 Vx, Vy。Vertex = (−4, 2) → 先寫 x − (−4)，最後先變 x + 4。

Tangent

目的：指定一隻角之後，準確搵出 opposite 同 adjacent。唔背長邊短邊，因為長短會變。

唯一比例
tan θ = oppositeadjacent
  1. 先搵 90°。
  2. 90° 正對面係 hypotenuse；先刪走，tan 唔用佢。
  3. 剩低兩條：指定角正對面係 opposite，放上面。
  4. 掂住指定角嗰條係 adjacent，放下面。
最緊要：Adjacent 唔等於「短嗰條」。只睇位置，唔睇長短。

Similar triangles

意思：形狀相同，只係整個三角形等比例放大或縮小。重點唔係背圖，而係保持配對同方向。

  1. 用相同角先搵 對應邊。
  2. 每個分數保持同方向：全程小/大，或者全程 A/B。
  3. 放入未知數，最後 cross multiply。
唔需要兩個三角形一樣大；只需要角度相同、邊按同一比例變。
固定比例 · 全程同方向
小邊₁對應大邊₁ = 小邊₂對應大邊₂

平方之後，有幾多個解？

目的：見到「一嚿嘢平方 = n」，唔使解晒條式，望右邊個 n 就知道有 0、1 定 2 個 distinct real solutions。

先望右邊
(括號入面)² = n

平方後一定大過或等於零。所以右邊係負數，根本冇可能；係零，括號只能係零；係正數，括號可以一正一負。

n < 0 平方冇可能變負數 0 個解
n = 0 只有 0² = 0 1 個解
n > 0 +√n 同 −√n 都得 2 個解

第 16 題個原理

(x + 15)² = 0

括號入面只能 = 0

x = −15

1 distinct real solution

  1. 唔使理括號入面幾複雜，先望右邊個 n。
  2. 負數 → 0 個；零 → 1 個；正數 → 2 個。
  3. 題目只問數量，就到此停手，唔使真的解 x。

正負兩種係「括號入面」，唔係話兩個 x 必定一正一負。
