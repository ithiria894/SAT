# SAT Math — Locked Formula Sheet

Nicole's visual, mobile-first SAT Math reference. It contains only formulae and
mechanical methods that have already been understood and deliberately locked in.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

The site is plain HTML/CSS/JavaScript and is published through GitHub Pages.

## Structure (2026-11-02)

6 topics, each one cheat-sheet image with the per-question example figures folded under it.
Rebuild with `python3 tools/build_topic_site.py` after regenerating the sheets in the corpus repo
(`docs/teaching-figures/make_topic_sheets.py`). Calculator advice is Casio fx-991ES Plus C only.
Old version: `archive/`.
